# UX Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix seven targeted UX gaps in the BearTracks admin and employee-facing UI without touching the backend.

**Architecture:** Five self-contained tasks: (1) shared utilities with tests, (2) wizard step labels, (3) admin form grouping, (4) input + table component consistency, (5) empty states. Admin page headings are already implemented and require no work. Each task can be reviewed independently.

**Tech Stack:** Next.js 16 App Router, JavaScript, shadcn/ui (Input, Table, Button), Tailwind CSS, Vitest + Testing Library.

## Global Constraints

- JavaScript only — no TypeScript
- No new npm dependencies
- `<select>` and `<textarea>` remain as plain HTML — only `<input type="text|email|number|date">` swap to shadcn `<Input>`; `<input type="color">` stays as plain HTML
- Admin tables use shadcn `Table` / `TableHeader` / `TableBody` / `TableRow` / `TableHead` / `TableCell` from `@/components/ui/table`
- No mobile layout changes
- No backend changes, no new routes, no database changes
